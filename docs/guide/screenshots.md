# Screenshots

A quick visual tour. Ready to try it for real? Head to [Install](/install).

## The commit graph

The home screen: a fast, virtualized swimlane graph with inline branch and tag chips, a clear "you are here" marker on HEAD, and a folder-tree sidebar. It stays smooth with readable text even on very large histories.

![The GitCat commit graph](/screenshots/graph.png)

## Commit detail and diff

Click any commit for the full picture: author and committer, signature status, the changed-file tree, and a syntax-highlighted diff.

![Commit detail panel with a syntax-highlighted diff](/screenshots/commit-detail.png)

## Command palette

Press `⌘K` to fuzzy-search commits, refs, and actions, or jump straight to a feature.

![The command palette](/screenshots/command-palette.png)

## Settings

Themes, graph layout, cherry-pick defaults, update channel, and this repository's git identity. The display language switches live.

![Settings](/screenshots/settings.png)

## In your language
